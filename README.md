# HoloLens Basketball Prototype

A small HoloLens/XR basketball prototype created as a university assignment.

> Portfolio documentation version  
> This project is an experimental XR prototype. The README documents the project goal, implemented systems, technical learnings, and current limitations.

## Overview

This project is a small mixed reality basketball prototype built for HoloLens. The goal was to experiment with XR interaction, spatial setup and basic Unity gameplay mechanics on HoloLens hardware.

## Features

- Basic basketball interaction prototype (picking up basketballs, throwing it and resetting timer and score)
- Unity XR/HoloLens setup
- Simple throwing or interaction logic
- Basic scene and object setup

## Technical Focus

- Unity XR development
- HoloLens project setup
- Mixed reality interaction basics
- Spatial interaction testing
- Prototype debugging on device/emulator

## Limitations

This project was a small university prototype and is not a polished game.
Some features are incomplete or unstable, and the project mainly serves as documentation of early XR/HoloLens experimentation.

## Project Context

This project was created as a university assignment.
It is included as a learning prototype, not as one of my main gameplay programming projects.
